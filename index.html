Geospatial, software and data engineer.

I am a geospatial, software and data engineer who bridges spatial data, backend/full-stack engineering, and cloud infrastructure. With a BSc in Geospatial Engineering from the University of Nairobi and a Kubernetes & Cloud Native Associate (KCNA) credential, I specialize in turning raw data and spatial datasets into automated pipelines, APIs, and production web applications. My work spans validating administrative boundaries in RealitySync (using PostGIS, dbt, GeoJSON, and GCP Cloud Build, accepted for IEEE AP-GARSS 2026), architecting multi-worker systems like EventFlow, building an agricultural market data ETL API (Pulse Price AI, winner of the Africa AI Week Hackathon 2025), and shipping a live full-stack ERP for Shwari Phones / Affordable Gadgets KE on GCP with Docker and Terraform.

What I am best suited for

  • Geospatial Software / Cloud GIS Engineer Roles that need someone who understands spatial data (PostGIS, GeoJSON, Rasterio, administrative boundaries) and can write production Python/TypeScript code, build APIs, and automate data pipelines—rather than relying solely on point-and-click GIS tools.
  • Spatial Data / Data & ETL Engineer Building automated ingestion, cleaning, transformation (dbt, Python, SQL), and validation workflows where data accuracy, structure, and reliability matter.
  • Backend or Full-Stack Engineer (Python / TypeScript) Building APIs (FastAPI, Django REST), relational/event-driven backends (PostgreSQL, Redis, CQRS/outbox patterns), and web interfaces (Next.js, React) for small-to-midsize teams or fast-moving product environments.
  • Cloud & DevOps-Oriented Application Engineer Setting up containerized deployments (Docker), Infrastructure as Code (Terraform, CloudFormation), CI/CD pipelines, and monitoring (Prometheus, Grafana) on cloud platforms like GCP or AWS.
  • Applied AI / Data Pipeline Builder (Early-Stage / Prototyping) Turning unstructured or domain-specific data (such as agricultural or spatial data) into usable APIs and applications, as shown by my hackathon win and applied projects.
